# HTTP/2 (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trace over HTTP/2 when a host supports it, choosing the protocol the way a browser would, and record why that choice was made.

**Architecture:** Framing moves out of `wj/collect/http.py` into a `wj/transport/` package behind the injectable `fetch(url, connection)` seam that already exists. A new `negotiate` collector runs between `dns` and `tcp`, decides the protocol from the host's HTTPS record, and sets the ALPN list the TLS handshake offers. `wj/collect/http.py` keeps everything protocol-independent — redirects, decoding, security grading, cache and CDN detection.

**Tech Stack:** Python 3.13+, the `h2` library (sans-IO HTTP/2 framing), `rich`, `dnspython`, `cryptography`, `pytest`.

**Spec:** `docs/superpowers/specs/2026-08-21-http2-http3-design.md`

## Global Constraints

- Project root: `/Users/razvanbalsan/Projects/webpage-journey`. Every python/pytest command runs as `.venv/bin/python …`.
- **Every field is either measured or absent.** Nothing renders, exports or asserts a value the trace does not carry. A section that could not be collected says `observed: false` with a real `why_not`.
- **A protocol downgrade must be recorded, never silently succeed.** Every rung of the fallback ladder is a measurement.
- **h2 failing after ALPN selected it is an error, not a fallback.** The server agreed to h2; silently retrying on HTTP/1.1 and reporting success would recreate the negotiate-one-speak-another mismatch this project already fixed once.
- **Unit tests never touch the network.** The `h2` library is sans-IO: drive a client and a server connection against each other through byte buffers. Network tests are marked `@pytest.mark.network` and deselected by default.
- **No schema major bump in Phase 1.** Every change here is additive; v1 consumers stay correct. The bump to `webpage-journey-trace/2` belongs to Phase 2.
- `webpage-journey.html` is ES5-flavoured (`var`, `function`, no arrow functions, optional chaining or template literals).
- The page stays ONE self-contained file. No CDN, no build step, no framework.
- Every task ends with a commit.

**One boundary decision worth stating up front.** `dechunk` moves to `h1.py` and h1's `fetch` returns an **already-dechunked** body. Transfer-encoding is a framing concern and does not exist in HTTP/2; content-encoding (gzip/br) is a payload concern and stays in `http.py`. This makes `decode_body` protocol-independent instead of quietly h1-shaped. Task 1 covers the change and its tests.

```python
import h2.config
import h2.connection
import h2.events
import pytest

from wj import capabilities
from wj.context import Context
from wj.transport import h2 as h2_transport


class FakeTLSSocket:
    """A socket-shaped object wired to a real server-side h2 connection.

    Whatever the transport sends is fed to the server; whatever the server
    produces is handed back on recv(). No network, but real framing on both
    sides — the client is tested against an actual HTTP/2 implementation.
    """

    def __init__(self, response_headers, body=b"", trailing_close=True):
        self.server = h2.connection.H2Connection(
            config=h2.config.H2Configuration(client_side=False))
        self.server.initiate_connection()
        self._response_headers = response_headers
        self._body = body
        self._trailing_close = trailing_close
        self._outbox = bytearray(self.server.data_to_send())
        self.closed = False

    def settimeout(self, _seconds):
        pass

    def sendall(self, data):
        events = self.server.receive_data(data)
        for event in events:
            if isinstance(event, h2.events.RequestReceived):
                self.server.send_headers(event.stream_id, self._response_headers)
                self.server.send_data(event.stream_id, self._body, end_stream=True)
        self._outbox += self.server.data_to_send()

    def recv(self, _size):
        if not self._outbox:
            return b"" if self._trailing_close else b""
        chunk = bytes(self._outbox)
        self._outbox = bytearray()
        return chunk

    def close(self):
        self.closed = True


def make_ctx():
    caps = capabilities.Capabilities(libs={"h2": True}, tools={},
                                     privileged=False, can_sudo=False)
    return Context(host="example.com", scheme="https", port=443, path="/",
                   timeout=5.0, deadline=1e9, caps=caps, results={})


def test_fetch_returns_the_normalised_shape_every_transport_returns():
    sock = FakeTLSSocket([(":status", "200"), ("content-type", "text/html")],
                         body=b"<html></html>")
    fetch = h2_transport.fetcher(make_ctx())
    response = fetch("https://example.com/", sock)

    assert response["protocol"] == "HTTP/2"
    assert response["status"] == 200
    assert ("content-type", "text/html") in response["headers"]
    assert response["body"] == b"<html></html>"
    assert response["ttfb_ms"] is not None
    assert response["wire_bytes"] == len(b"<html></html>")

    assert all(not k.startswith(":") for k, _ in response["headers"])
```

```python
"""HTTP/2 framing over the TLS socket the TLS collector already opened.

The h2 library is sans-IO: it turns events into bytes and bytes into events,
and never touches a socket. That is why this transport can keep the socket we
measured — the kernel TCP_INFO readings and the timed TLS handshake stay
valid, which they would not if a client library owned the connection.
"""

import time

from wj.transport.h1 import build_request


class TransportUnavailable(Exception):
    """Raised when this build cannot speak the protocol it was asked for."""


def _connection_state(sock):
    """One h2 connection per socket, so a reused socket continues its stream
    numbering instead of restarting at 1."""
    state = getattr(sock, "_wj_h2", None)
    if state is None:
        import h2.config
        import h2.connection

        conn = h2.connection.H2Connection(
            config=h2.config.H2Configuration(client_side=True))
        conn.initiate_connection()
        sock.sendall(conn.data_to_send())
        state = {"conn": conn}
        setattr(sock, "_wj_h2", state)
    return state


def fetcher(ctx):
    if not ctx.caps.has_lib("h2"):
        raise TransportUnavailable("the h2 library is not installed")

    import h2.events

    def fetch(url, sock):
        state = _connection_state(sock)
        conn = state["conn"]

        request = build_request(url)
        headers = [(":method", request["method"]),
                   (":path", request["target"]),
                   (":scheme", "https"),
                   (":authority", dict(request["headers"]).get("Host", ""))]
        headers += [(k.lower(), v) for k, v in request["headers"]
                    if k.lower() != "host"]

        stream_id = conn.get_next_available_stream_id()
        sock.settimeout(ctx.budget_for(ctx.timeout))
        started = time.perf_counter()

        conn.send_headers(stream_id, headers, end_stream=True)
        wire_before = len(conn.data_to_send.__self__._data_to_send) if False else 0
        outgoing = conn.data_to_send()
        sock.sendall(outgoing)

        response_headers = []
        body = bytearray()
        header_wire_bytes = 0
        ttfb = None
        done = False

        while not done:
            try:
                data = sock.recv(65536)
            except OSError:
                break
            if not data:
                break
            for event in conn.receive_data(data):
                if isinstance(event, h2.events.ResponseReceived) and event.stream_id == stream_id:
                    if ttfb is None:
                        ttfb = round((time.perf_counter() - started) * 1000, 1)
                    response_headers = list(event.headers)
                    header_wire_bytes = getattr(event, "header_encoded_size", 0) or 0
                elif isinstance(event, h2.events.DataReceived) and event.stream_id == stream_id:
                    body += event.data
                    conn.acknowledge_received_data(len(event.data), event.stream_id)
                elif isinstance(event, h2.events.StreamEnded) and event.stream_id == stream_id:
                    done = True
            pending = conn.data_to_send()
            if pending:
                sock.sendall(pending)

        decoded = _decode_headers(response_headers)
        return {
            "protocol": "HTTP/2",
            "status": decoded["status"],
            "reason": None,          # HTTP/2 has no reason phrase; absent, not ""
            "headers": decoded["headers"],
            "body": bytes(body),
            "ttfb_ms": ttfb,
            "total_ms": round((time.perf_counter() - started) * 1000, 1),
            "wire_bytes": len(body),
            "stream_id": stream_id,
            "header_bytes": {"wire": header_wire_bytes,
                             "decoded": _decoded_header_size(response_headers)},
        }

    return fetch


def _decode_headers(raw_headers):
    """Split h2's pseudo-headers from real ones.

    :status carries the status code; it is not a header a reader should see
    listed beside content-type, and it must not reach the security grader.
    """
    status = None
    headers = []
    for name, value in raw_headers:
        name = name.decode() if isinstance(name, bytes) else name
        value = value.decode() if isinstance(value, bytes) else value
        if name == ":status":
            status = int(value)
        elif not name.startswith(":"):
            headers.append((name, value))
    return {"status": status, "headers": headers}


def _decoded_header_size(raw_headers):
    """Bytes these headers would occupy uncompressed, as HTTP/1.1 would send them."""
    total = 0
    for name, value in raw_headers:
        name = name.decode() if isinstance(name, bytes) else name
        value = value.decode() if isinstance(value, bytes) else value
        if name.startswith(":"):
            continue
        total += len(name) + len(value) + 4      # ": " and CRLF
    return total
```

## Task 3: The negotiate collector

**Files:**
- Create: `wj/collect/negotiate.py`
- Modify: `wj/run.py`, `wj/schema.py`, `wj/collect/tls.py`
- Test: `tests/test_collect_negotiate.py`

**Interfaces:**
- Consumes: `ctx.results["dns"]["alpn_advertised"]` (list of protocol tokens from the host's
  HTTPS/SVCB record), `ctx.caps.has_lib("h2")`, `ctx.scheme`.
- Produces:
  - `wj.collect.negotiate.choose(advertised, caps, scheme) -> dict` — a pure function
  - `wj.collect.negotiate.collect(ctx) -> dict` — the section
  - Section shape: `{"observed": True, "advertised": [...], "signal": str, "offered": [...],
    "chosen": None, "attempted": []}`. `chosen` stays `None` here — the protocol is not known
    until ALPN completes in the TLS handshake, and claiming it earlier would assert something
    unmeasured. Task 4 fills it in from what the server actually selected.
  - `wj.schema.SECTIONS` gains `"negotiation"`
  - `wj.collect.tls.ALPN_PROTOCOLS` is replaced by per-run selection

**The distinction this task turns on:** what we *offer* is our own decision and is known now.
What is *chosen* is the server's decision and is not known until the handshake. The section
separates them. Recording `chosen` before the handshake would be exactly the fabrication this
project keeps removing.

```python
"""Choose the protocol the way a browser would, and record why.

A browser decides whether to try HTTP/3 from the host's HTTPS/SVCB record,
because that is the only signal available before the first connection —
Alt-Svc only helps on a return visit, which a one-shot tracer never has.
Phase 1 uses the same signal to decide whether to offer HTTP/2.

What we OFFER is our decision and is known now. What is CHOSEN is the
server's decision, known only once ALPN completes in the TLS handshake.
The section keeps them apart; claiming a protocol before the handshake
would assert something unmeasured.
"""

from wj.schema import observed, unobserved

H1 = "http/1.1"
H2 = "h2"


def choose(advertised, caps, scheme):
    """Decide what to offer over ALPN. Pure — no I/O, no context."""
    advertised = list(advertised or [])

    if scheme != "https":
        return {"advertised": advertised, "offered": [],
                "signal": "no TLS — ALPN does not apply", "unavailable": []}

    unavailable = []
    offered = []

    if H2 in advertised:
        if caps.has_lib(H2):
            offered.append(H2)
        else:
            unavailable.append(H2)

    offered.append(H1)

    signal = "HTTPS record" if advertised else "no HTTPS record"
    return {"advertised": advertised, "offered": offered,
            "signal": signal, "unavailable": unavailable}


def collect(ctx):
    dns = ctx.results.get("dns", {})
    if not dns.get("observed"):
        return unobserved(
            f"skipped because dns was not observed: {dns.get('why_not', 'unknown')}")

    decision = choose(dns.get("alpn_advertised"), ctx.caps, ctx.scheme)
    return observed(
        advertised=decision["advertised"],
        offered=decision["offered"],
        signal=decision["signal"],
        unavailable=decision["unavailable"],
        chosen=None,        # filled in by the http collector from the handshake
        attempted=[],
    )
```

```python
def render_negotiation_line(console, trace):
    """One line, not a panel — which protocol was chosen and on what evidence."""
    section = trace.get("negotiation", {})
    if not section.get("observed"):
        console.print(f"[dim]Protocol negotiation not observed — "
                      f"{section.get('why_not', 'not collected')}[/dim]")
        return

    advertised = ", ".join(section.get("advertised") or []) or "nothing"
    offered = ", ".join(section.get("offered") or []) or "nothing (no TLS)"
    chosen = section.get("chosen")
    tail = f"chose {chosen}" if chosen else "no protocol selected"
    console.print(f"[dim]Host advertises {advertised} "
                  f"({section.get('signal', 'unknown signal')}) · "
                  f"offered {offered} · {tail}[/dim]")
```
